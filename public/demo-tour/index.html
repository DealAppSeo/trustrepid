Mint a SoulBound Token

Connect your wallet, sign a server-issued challenge, get back a token id + IPFS metadata URI + audit-chain entry. v0.1 defaults to MOCK mode (set SBT_MINT_MOCK=0 + a funded deployer wallet to switch on real on-chain mints).

3

Prove a RepID threshold

Generate a zero-knowledge proof that R >= T without revealing R. v0.1 uses an HMAC stub — Sprint 3 swaps in a real Plonky3 circuit. The response shape is stable across the swap.

Open RepID prover spec
4

Verify the audit chain

Every mint and every proof emits a row to hal_audit_chain, hash-chained to the previous row. Range-verify any window to confirm integrity yourself.

Verify directly from chain

None of these pages is a black box. Every claim resolves to either an on-chain query against 0x8004A818BFB912233c491871b3d84c89A494BD9e on Base Sepolia, or a hash-chain row in hal_audit_chain that anyone can re-hash.
